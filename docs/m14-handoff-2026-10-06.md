## 7. Lessons from this session (also in LEARNING_LOG.md "Lessons so far")

- Ask reviewers "which bug passes every test?", then mutate it; check a
  surviving mutation changed behaviour at all (equivalent mutations exist).
- A mutation that crashes (a missing import) is not the assertion failing.
- Look at laptop-height and full-page screenshots; measure layout bugs in
  the browser before changing CSS, then turn the measurement into a test.
- Never leave a large wrapper focusable (Safari focuses it on click).
- A new accessible name must not contain another control's label
  (Playwright matches substrings).
- In this Next.js, any `revalidatePath` inside a server action refreshes
  the sidebar (layout); removing all of them leaves it stale.
- zsh passes `$VAR` holding two paths as one argument.
- Change the colour scheme before loading a page when measuring contrast.
