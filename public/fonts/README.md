Copies of the bundled fonts for use **inside book pages** in the reader
(book pages are separate documents that cannot see the app's own fonts).
From `@fontsource-variable/source-serif-4` and `@fontsource-variable/source-sans-3`
(latin subset), SIL Open Font License 1.1 (see the LICENSE files here).
Re-copy them if those packages are upgraded.

`stix-two-math.woff2`: STIX Two Math, for formulas in book pages (M41), from
`@fontsource/stix-two-math` 5.3.0 (`files/stix-two-math-latin-400-normal.woff2`;
it keeps the font's MATH table, which lets brackets stretch). SIL Open Font
License 1.1 (`LICENSE-stix-two-math.txt`).
