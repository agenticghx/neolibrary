# Word substitutions

A practical working subset. The official ASD-STE100 dictionary has roughly 900
approved words and about 1,200 non-approved words with alternatives; it is
copyrighted and free to obtain from <https://www.asd-ste100.org>. Use this file to
move quickly on ordinary text, and the official dictionary for anything regulated or
contractual.

The replacement that fits depends on the sentence. Read the "why" column before you
substitute — several of these words are non-approved precisely because they mean more
than one thing, so there is no single correct swap.

## Words with more than one meaning

These cause the most damage, because both readings are plausible and the reader
cannot tell which you meant.

| Avoid | Use | Why |
|---|---|---|
| since | after · because | time or cause |
| while | when · although | time or contrast |
| as | because · when · like | many senses |
| once | when · one time | time or count |
| following | after · these | preposition or adjective |
| may | can · is permitted to · is possible | permission or possibility |
| should | must · we recommend that | requirement or advice |
| only | Move it next to the word it limits | position changes the meaning |
| free | free of charge · loose · not attached | three senses |
| light | not heavy · illumination · pale | three senses |
| right | correct · right side | two senses |
| close | shut (verb) · near (use `near`) | verb or adjective |
| left | left side · remaining (use `remaining`) | two senses |

## Verbs with restricted parts of speech

The approved dictionary often lists a word as a noun only. Rephrase with `do`,
`make`, `give`, or `apply` plus the noun.

| Avoid | Use |
|---|---|
| to test the unit | to do a test of the unit |
| to sample the buffer | to take a sample of the buffer |
| to plot the results | to make a plot of the results |
| to impact | to have an effect on · to change |
| to reference | to refer to |
| to task someone | to give a task to someone |
| to trial | to do a trial of |
| to interface with | to connect to |
| to leverage | to use |
| to action | to do |

## Continuous and perfect forms

| Avoid | Use |
|---|---|
| is operating | operates |
| was running | ran |
| has completed | completed · is complete |
| have been removed | are removed · were removed |
| had been damaged | was damaged |
| will have finished | finishes · will finish |
| is being processed | *name the actor*: the system processes it |
| must be able to be removed | you can remove |

## The -ing form

| Avoid | Use |
|---|---|
| Before starting the pump, … | Before you start the pump, … |
| Cleaning is necessary. | You must clean the unit. |
| After completing the test, … | After you complete the test, … |
| Using a 10 mm wrench, remove… | Use a 10 mm wrench. Then remove… |
| The pump, operating at 30 bar, … | The pump operates at 30 bar. It … |

Keep an -ing word when it is part of a technical name: `landing gear`,
`sequencing library`, `binding site`, `operating system`.

## Passive to active

| Avoid | Use |
|---|---|
| The switch must be turned to OFF. | Turn the switch to OFF. |
| The sample should be centrifuged. | Centrifuge the sample. |
| It was found that the seal had failed. | The seal failed. |
| The data were analysed with DESeq2. | We analysed the data with DESeq2. |
| The filter is to be replaced annually. | Replace the filter each year. |

In descriptive text, the passive is permitted when the actor is unknown or genuinely
does not matter. In an instruction it never is, because the actor is the reader.

## Words to keep

Do not substitute these away.

- **Technical names**: part numbers, chemical names, gene symbols, tool names,
  software names, file formats, units.
- **Technical verbs**: `centrifuge`, `anneal`, `titrate`, `autoclave`, `torque`,
  `align`, `calibrate` — discipline-specific actions with no approved equivalent.
- **Numbers, units, equations, code, identifiers.**
- **Modal distinctions**: `must` (requirement), `can` (ability or permission),
  `will` (future). Keep the distinction the author intended.
